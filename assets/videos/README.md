# リール用の動画置き場

ここに自作の縦動画を **連番** で置くと、リールタブと検索タブが自動で拾います。

```
assets/videos/reel1.mp4
assets/videos/reel2.mp4
...
assets/videos/reel10.mp4
```

## 仕様（推奨）
| 項目 | 推奨 |
|---|---|
| 向き | 縦 9:16 |
| 解像度 | 720×1280（グリッド用途だけなら 360×640 でも十分） |
| 長さ | 5〜15秒（ループ再生されるので短くてOK） |
| 形式 | MP4（H.264） |
| サイズ | 1本 1〜3MB 以内が理想 |
| 音声 | 無しでOK（ブラウザ仕様で自動再生は必ずミュートになる） |

## 仕組み
- コードは `reel1.mp4` から順に読み込みを試します
- **ファイルが無い番号は自動でフリー素材（Pexels）にフォールバック**します
- なので「何本置くか」を気にせず、増やしたぶんだけ勝手に反映されます。コード修正は不要

## 公開についての注意
デプロイ（Vercel）や GitHub への push をすると、ここに置いた動画は **公開されます**。
- 顔が映るのはOK（本人判断済み）
- **自宅の場所が特定できるもの・家族が映るものは置かない**こと
