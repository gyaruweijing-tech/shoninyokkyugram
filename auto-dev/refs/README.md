# refs — 完コピ用スクショ置き場

**1機能 = 1フォルダ。** 撮ったスクショを、対応するIDのフォルダに放り込むだけでよい。

## 入れ方

1. `../ROADMAP.md` でやってほしい機能のIDを見る（例: アーカイブ = `S03`）
2. `refs/` の中の **そのIDで始まるフォルダ** を開く（例: `S03-archive/`）
3. 黒塗り済みのスクショを放り込む。**枚数は何枚でもよい**

**ファイル名は自由。** `IMG_1234.PNG` のままでよい。Routineが中の画像を1枚ずつ見て
「これはカレンダータブだな」と判別する。順番を伝えたい時だけ `1.png` `2.png` … と付ける。

## 何枚撮ればいい？

**その画面のタブ・状態を全部。** 1枚で足りる画面はむしろ少ない。
- アーカイブ → ストーリーズ / ハイライト / カレンダー / マップ の4タブ = 4枚
- 保存済み(S02) → 6タブで5枚使った
- 空状態・入力中・メニューを開いた状態なども、その挙動を再現してほしいなら撮る

**画像が1枚でも入っていればRoutineはその機能に着手できる。** 0枚ならスキップされる
（＝撮った順に開発が進む。**フォルダに入れた瞬間にキューに入る**）。

## プライバシー（入れる前に必ず）

**必要なのはUIの骨格（タブ・アイコン・文言・配置）だけ。中身の写真・実データは一切要らない。**
だから塗る面積をケチる理由がゼロ。迷ったら塗る。

必ず単色の黒でベタ塗りするもの:

| 対象 | 理由 |
|---|---|
| 位置情報（マップタブ・位置スタンプ） | 自宅・生活圏の特定。最優先 |
| QRコード | 読めばアカウントURLがそのまま出る（画像に見えて生データ） |
| 顔（自分・友人・家族） | 他人の顔は自分の判断で出す権利がない |
| ユーザーネーム / @ハンドル / 本名 | |
| メールアドレス・電話番号 | アカウントセンター内に出る |
| フォロワー / フォロー実数 | 身元照合の手がかり |
| DMの相手名・本文 | |
| 投稿・ストーリーのサムネ画像 | 生活が丸ごと分かる |

- **モザイク・ぼかしは禁止**（元情報が残っており復元されうる）。**単色の黒**のみ
- 加工は **PCの「ペイント」推奨**。レイヤーの概念が無くピクセルを直接上書きするため剥がせない。
  保存時にEXIFも落ちる（編集前サムネイルの残留が起きない）
- LINE等に送って加工するのは、原本が外部サーバーに渡るので避ける
